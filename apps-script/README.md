# MarvelMarka в Google Apps Script

Это закрытая совместная версия Marvel Timeline Board. Внешне она остаётся отдельным сайтом, а Google Таблица используется как база данных и список доступа.

## Что хранится в Google

- Лист `Доступ` — разрешённые Google-аккаунты и их роли.
- Скрытый лист `Карта` — просмотренные фильмы, заметки, координаты и размеры фотографий.
- Скрытый лист `История` — журнал основных изменений.
- Закрытая папка Drive — загруженные фотографии.

## Первичная публикация

### 1. Создайте Apps Script

1. Откройте [script.google.com](https://script.google.com/) под аккаунтом владельца.
2. Нажмите **Новый проект** и назовите его `MarvelMarka`.
3. Создайте файлы с точными именами и скопируйте содержимое из этой папки:
   - `Code.gs`
   - `Index.html`
   - `Styles.html`
4. В настройках проекта включите показ файла манифеста и замените `appsscript.json`.

Клиентский JavaScript хранится в `public/apps-script-client.js` и подключается через CDN, чтобы HTML-сервис Google не изменял его содержимое.

### 2. Создайте общую таблицу и папку

1. Выберите функцию `setupProject` в верхней панели редактора.
2. Нажмите **Выполнить**.
3. Подтвердите запрошенные Google-разрешения.
4. Откройте журнал выполнения — функция вернёт ссылки на таблицу и папку.

Владелец автоматически появится первой строкой на листе `Доступ`.

### 3. Опубликуйте сайт

1. Нажмите **Начать развёртывание → Новое развёртывание**.
2. Тип: **Веб-приложение**.
3. Выполнять приложение от имени: **Пользователь, обращающийся к веб-приложению**.
4. Доступ: **Все пользователи с аккаунтом Google**.
5. Нажмите **Развернуть** и скопируйте URL `/exec`.

Настройка «от имени пользователя» обязательна: только в этом режиме сервер получает email посетителя и может сверить его с листом `Доступ`.

## Как добавить второго человека

Есть два способа:

1. Откройте сайт → нажмите на аватар справа → заполните email → **Добавить доступ**.
2. Либо добавьте строку вручную на лист `Доступ`: email, имя, включите флажок, укажите роль `member`. Установленный триггер автоматически синхронизирует права таблицы и папки.

Сами листы `Карта` и `История` скрыты, однако участнику с ролью редактора Google Drive технически доступно их раскрытие. Основная проверка доступа всё равно выполняется сервером при каждом запросе сайта.

## Обновление версии

После изменения кода:

1. **Начать развёртывание → Управление развёртываниями**.
2. Выберите существующее веб-приложение.
3. Создайте новую версию и нажмите **Развернуть**.

Постоянный адрес `/exec` при этом не меняется.

## Ограничения

- Фотография после загрузки уменьшается максимум до 1800 px по длинной стороне.
- После сжатия размер фотографии должен быть не больше 2,5 МБ.
- Синхронизация открытых вкладок выполняется примерно раз в 6 секунд.
- Это решение рассчитано на небольшую частную группу, а не на сотни одновременных пользователей.
