# Marvel Timeline Board

Основной сайт на Next.js находится в папке `app`. Закрытая совместная версия на Google Apps Script находится в [`apps-script`](./apps-script/README.md).

Интерактивная карта фильмов киновселенной Marvel в формате бесконечной доски.

## Возможности

- масштабирование колесом относительно точки под курсором;
- свободное перемещение по карте;
- отметки просмотренных фильмов с локальным сохранением;
- добавление, изменение размера и удаление фотографий;
- текстовые заметки и пользовательские фотографии с исходными пропорциями;
- прямые ссылки на страницы фильмов на SSpoisk.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Vercel

Проект использует стандартный Next.js и не требует специальной конфигурации. Импортируйте GitHub-репозиторий в Vercel и оставьте автоматически определённые параметры сборки.
